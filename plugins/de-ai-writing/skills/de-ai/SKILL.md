# De-AI Writing

## Apply the Core Contract

- Treat AI flavor as a contextual style diagnosis, not proof of AI authorship. Never claim that a phrase or text was generated by AI.
- Preserve the author's meaning, factual claims, stance, terminology, citations, numbers, notation, and formatting unless the user asks to change them.
- Never introduce or retain em dashes (`—` or `——`) or en dashes (`–`) as sentence punctuation in generated or rewritten prose. Replace them with commas, colons, parentheses, semicolons, or sentence breaks. Preserve non-punctuation marks required by the content, including hyphens in compound terms and command flags, minus signs, numerical ranges, code, filenames, and citation keys.
- Minimize and, whenever possible, eliminate defensive language. Remove blame, reader-directed correction, preemptive justification, excessive apology or deference, and meta-claims such as “obviously” or “as clearly stated.” Replace them with the factual answer, evidence, scope, or limitation. Retain only wording needed to express a substantive disagreement, correct a material factual error, or preserve warranted uncertainty, and state it neutrally.
- Respect the exact requested scope. Use surrounding text only to understand context; do not review or edit outside the requested scope.
- Prefer no change over a cosmetic change that weakens precision or voice.
- Say that the text already reads naturally when no material issue is present.

## Select the Operating Mode

Infer the mode from the user's verb. Do not ask when the request is clear.

| Mode | Typical Request | Action |
|---|---|---|
| **Audit** | check, review, 有没有 AI 味 | Diagnose material issues and suggest local fixes. Do not rewrite the whole passage. |
| **Rewrite** | de-AI, polish, rewrite, 去 AI 味, 润色 | Return a revised version first, followed by a brief change summary. |
| **Direct edit** | edit/modify this file, 直接改文件 | Patch only the specified file or section, then verify the diff. |
| **Audit + rewrite** | check and fix, 找问题并修改 | Give a short diagnosis, then a revised version. |

If the user requests a particular format, follow it instead of the defaults below.

## Follow the Workflow

1. Determine the operating mode, requested scope, language, audience, genre, and intended tone.
2. Read the complete requested passage before flagging local phrases.
3. Load the primary scenario reference.
4. Scan all seven dimensions using the primary and secondary priorities in the scenario reference; report only material findings.
5. Calibrate each finding from repetition, clustering, context, and effect on the reader.
6. Distinguish AI-flavor signals from ordinary writing-quality problems.
7. Respond according to the selected mode.
8. Verify that the result preserves facts, claims, citations, terminology, numbers, code, and requested formatting, then scan the final prose for prohibited dash punctuation and avoidable defensive language.

## Check Seven Dimensions

| Dimension | Check |
|---|---|
| Logical coherence | Motivation, causal chain, prerequisites, concept order |
| Transition naturalness | Genuine progression rather than connector or keyword chaining |
| Formulaic expression | Repeated genre templates, empty signposting, symmetrical filler |
| Directness | Unnecessary preambles, fake contrasts, defensive clarification, nominalization |
| Vocabulary naturalness | Translation artifacts, vague intensifiers, imprecise verbs, term stacking |
| Sentence complexity | Parsing burden, nested clauses, overloaded observation–interpretation–implication chains |
| Term consistency | Stable names, expanded acronyms, audience-appropriate terminology |

## Calibrate Evidence and Severity

Label each reported issue as either:

- **AI signal**: a contextual pattern associated with formulaic or generic model prose.
- **Writing quality**: a clarity, logic, grammar, or consistency problem that is not specifically evidence of AI flavor.

Treat isolated words, stock phrases, sentence length, passive voice, first-person absence, and contribution lists as weak signals. Do not assign high severity from any one of them alone.

- **High**: The issue distorts or overstates meaning, materially blocks comprehension, or forms a repeated cluster that dominates the passage.
- **Medium**: The pattern is repeated, contextually inappropriate, or noticeably flattens the author's voice.
- **Low**: The issue is isolated and optional to improve.

Preserve warranted hedging in academic, legal, medical, policy, and rebuttal writing. Directness must not become overclaiming.

## Use Compact Output by Default

### Audit

Start with one overall sentence. Report the strongest findings only; do not list dimensions with no issues.

```text
- [中 | AI信号 | 模板化表达 | 第 2 段]
  原文：...
  问题：...
  建议：...
```

For long texts, report the strongest 3–8 findings and state whether more minor issues remain. If the user explicitly asks for a complete, exhaustive, full, 全面, 完整, or 逐段 audit, perform the full audit. For inputs too long for one useful response, work section by section and maintain one consolidated issue index.

### Rewrite

Return:

1. The revised text
2. A short list of the main changes
3. Any ambiguity or factual point that needs the user's confirmation

Do not bury the revised text under a long diagnosis.

### Direct Edit

Edit only the requested scope. Summarize what changed and verify that unrelated content remained untouched.

## Preserve Integrity

- Do not invent evidence, examples, numbers, citations, personal reactions, or author intentions.
- Do not strengthen novelty, causality, certainty, or benchmark claims.
- Do not replace precise technical language with generic conversational prose.
- Keep LaTeX commands, citation keys, Markdown links, code, API names, and variable names intact unless explicitly asked to change them.
- Match the intended register. Do not make papers chatty, documentation promotional, or personal writing artificially formal.
- Before editing a long document, build an internal `concept → canonical term` map from the source. After editing, scan for variants, acronym expansion, capitalization, and unintended renaming.
